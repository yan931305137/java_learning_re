# Java 运算符（Operators）

Java 支持多种类型的运算符，主要分为以下几类：

* * *

## 一、算术运算符（Arithmetic Operators）

| 运算符 | 含义  | 示例  | 结果  |
| --- | --- | --- | --- |
| `+` | 加法  | `5 + 3` | 8   |
| `-` | 减法  | `5 - 3` | 2   |
| `*` | 乘法  | `5 * 3` | 15  |
| `/` | 除法  | `5 / 2` | 2   |
| `%` | 取模  | `5 % 2` | 1   |

> 注意：整数除法会丢弃小数部分，使用 `double` 类型可以保留小数。

* * *

## 二、关系运算符（Relational / Comparison Operators）

| 运算符 | 含义  | 示例  | 结果类型 |
| --- | --- | --- | --- |
| `>` | 大于  | `5 > 3` | `true` |
| `<` | 小于  | `5 < 3` | `false` |
| `>=` | 大于等于 | `5 >= 3` | `true` |
| `<=` | 小于等于 | `5 <= 3` | `false` |
| `==` | 等于  | `5 == 5` | `true` |
| `!=` | 不等于 | `5 != 3` | `true` |

* * *

## 三、逻辑运算符（Logical Operators）

| 运算符 | 含义  | 示例  | 结果  |
| --- | --- | --- | --- |
| `&&` | 逻辑与 | `true && false` | `false` |
| `   |     | `   | 逻辑或 |
| `!` | 逻辑非 | `!true` | `false` |

* * *

## 四、位运算符（Bitwise Operators）

| 运算符 | 含义  | 示例  |
| --- | --- | --- |
| `&` | 按位与 | `5 & 3 = 1` |
| `   | `   | 按位或 |
| `^` | 按位异或 | `5 ^ 3 = 6` |
| `~` | 按位取反 | `~5 = -6` |
| `<<` | 左移  | `5 << 1 = 10` |
| `>>` | 右移  | `5 >> 1 = 2` |
| `>>>` | 无符号右移 | `-1 >>> 1` |

* * *

## 五、赋值运算符（Assignment Operators）

| 运算符 | 含义  | 示例  |
| --- | --- | --- |
| `=` | 赋值  | `a = 5` |
| `+=` | 加后赋值 | `a += 5` |
| `-=` | 减后赋值 | `a -= 3` |
| `*=` | 乘后赋值 | `a *= 2` |
| `/=` | 除后赋值 | `a /= 4` |
| `%=` | 模后赋值 | `a %= 2` |
| `&=` | 按位与赋值 | `a &= 1` |
| `   | =`  | 按位或赋值 |
| `^=` | 按位异或赋值 | `a ^= 3` |
| `<<=` | 左移赋值 | `a <<= 1` |
| `>>=` | 右移赋值 | `a >>= 1` |
| `>>>=` | 无符号右移赋值 | `a >>>= 1` |

* * *

## 六、条件运算符（三元运算符）

语法：

    条件表达式 ? 表达式1 : 表达式2;

示例：

    int max = (a > b) ? a : b;

* * *

## 七、自增和自减运算符

| 运算符 | 含义  | 示例  |
| --- | --- | --- |
| `++` | 自增（前或后） | `a++`, `++a` |
| `--` | 自减（前或后） | `a--`, `--a` |

* * *

## 八、其他运算符

| 运算符 | 含义  | 示例  |
| --- | --- | --- |
| `instanceof` | 判断对象是否为某类 | `obj instanceof String` |
| `typeof` | ❌ Java 中无该运算符 | 可使用 `obj.getClass()` 获取类型 |

* * *

## 九、运算符优先级（部分示意）

从高到低：

    () > ++ -- > * / % > + - > << >> >>> > > < >= <= > == != > & > ^ > | > && > || > ?: > = += -= ...

可以使用括号 `()` 来显式改变运算顺序，避免歧义。

* * *

## ✅ 小结口诀

    加减乘除要记牢，关系比较真假道；
    逻辑运算分真假，位运进阶细思考；
    赋值简化加复合，自增自减真奇妙；
    三目判断效率高，instanceof判断好。

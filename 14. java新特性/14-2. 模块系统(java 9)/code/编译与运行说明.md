 编译和运行模块

**编译模块**
使用javac命令编译模块，指定模块路径。
命令示例：javac -d out --module-source-path src $(find src -name "*.java")

**运行模块**
使用java命令运行模块，指定模块路径。
命令示例：java --module-path out -m com.example.module/com.example.package.code.Main

**使用说明**
1. **创建模块描述符**：在模块的根目录下创建module-info.java文件，定义模块的名称、依赖和导出包。
2. **编写主类**：在模块中创建一个主类，作为应用程序的入口点。
3. **编译模块**：使用javac命令编译模块，确保指定正确的模块路径。
4. **运行模块**：使用java命令运行模块，确保指定正确的模块路径和主类。
